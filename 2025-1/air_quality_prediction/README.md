# air_quality_prediction

## 프로젝트 소개

**air_quality_prediction**은 UCI Air Quality 데이터셋을 활용하여 공기질 측정 데이터를 분석하고, 딥러닝 모델로 **벤젠 농도(`C6H6(GT)`)를 예측**하는 프로젝트입니다.

데이터 전처리와 시각화를 통해 주요 대기오염 물질 및 센서 변수의 특성을 살펴보고, 벤젠 농도와의 상관관계에 따라 입력 변수를 두 그룹으로 나눕니다. 이후 **RNN, LSTM, GRU, 1D CNN** 모델을 각각 학습하여 입력 변수 그룹에 따른 예측 성능을 비교합니다.

## 프로젝트 주요 내용

- **데이터 전처리:** 불필요한 열 및 결측 행 제거, 날짜·시간 통합, 결측값 코드 `-200` 처리
- **탐색적 데이터 분석:** 주요 오염물질의 시간별 변화와 변수 간 상관관계 시각화
- **입력 변수 그룹 구성:** `C6H6(GT)`와의 상관계수 절댓값을 기준으로 높은/낮은 상관관계 그룹 구분
- **딥러닝 모델 학습:** RNN, LSTM, GRU, 1D CNN을 이용한 시계열 예측
- **성능 비교:** 테스트 데이터의 MSE, MAE 및 실제값·예측값 그래프 비교

## 사용 데이터

예측 대상은 **벤젠 농도(`C6H6(GT)`)**입니다. 입력 변수 분석에는 다음과 같은 공기질·환경 측정값이 사용됩니다.

| 구분 | 주요 변수 |
| --- | --- |
| 대기오염물질 측정값 | `CO(GT)`, `C6H6(GT)`, `NOx(GT)`, `NO2(GT)` |
| 센서 응답값 | `PT08.S1(CO)`, `PT08.S2(NMHC)`, `PT08.S3(NOx)`, `PT08.S4(NO2)`, `PT08.S5(O3)` |
| 환경 변수 | `T`(온도), `RH`(상대습도), `AH`(절대습도) |

CSV 파일은 **세미콜론(`;`) 구분자와 쉼표(`,`) 소수점** 형식을 사용합니다.

### 데이터 전처리

1. CSV 파일을 불러와 비어 있는 열과 결측 행을 제거합니다.
2. `Date`와 `Time`을 합쳐 `Datetime` 인덱스를 생성합니다.
3. 분석 대상 열을 숫자 형식으로 변환합니다.
4. 결측값을 나타내는 `-200`을 결측치로 처리한 후 해당 행을 제거합니다.
5. 모델 입력과 예측 대상값을 `MinMaxScaler`로 정규화합니다.

> **참고:** 첨부된 데이터와 현재 전처리 코드 기준으로 결측값 포함 행을 모두 제거하면 **827개 관측치**가 남습니다. 관측 시점 사이에 간격이 생길 수 있으므로, 아래의 시퀀스 길이 24는 반드시 연속된 24시간을 의미하지는 않습니다.

## 입력 변수 그룹 및 예측 모델

### 1. 상관관계 기반 변수 그룹

벤젠 농도 `C6H6(GT)`와 다른 변수들 사이의 **피어슨 상관계수**를 계산하고 다음 두 그룹을 구성합니다.

| 그룹 | 선정 기준 | 현재 데이터에서 선정된 변수 |
| --- | --- | --- |
| 높은 상관관계 그룹 | 상관계수 절댓값 **0.9 이상** | `CO(GT)`, `PT08.S1(CO)`, `PT08.S2(NMHC)`, `NOx(GT)`, `PT08.S4(NO2)` |
| 낮은 상관관계 그룹 | 상관계수 절댓값 **0.5 이하** | `T`, `RH`, `AH` |

두 그룹은 각각 독립적으로 모델 학습과 평가에 사용되며, 예측 대상인 `C6H6(GT)` 자체는 모델 입력에서 제외됩니다.

### 2. 예측 모델

| 모델 | 구성 |
| --- | --- |
| RNN | 은닉 크기 64, 2개 층, 마지막 시점 출력을 이용한 회귀 |
| LSTM | 은닉 크기 64, 2개 층, 마지막 시점 출력을 이용한 회귀 |
| GRU | 은닉 크기 64, 2개 층, 마지막 시점 출력을 이용한 회귀 |
| 1D CNN | 필터 64개, 커널 크기 3, ReLU, Adaptive Max Pooling 및 회귀 출력층 |

각 모델은 이전 **24개 관측 시점**의 입력 변수를 활용하여 다음 관측 시점의 벤젠 농도를 예측합니다.

### 3. 학습 설정

| 항목 | 설정 |
| --- | --- |
| 학습/테스트 데이터 | 80% / 20% (시간 순서 유지) |
| 시퀀스 길이 | 24 |
| 학습 횟수(Epochs) | 100 |
| 배치 크기 | 64 |
| 최적화 알고리즘 | Adam |
| 학습률 | 0.001 |
| 손실 함수 | MSE |
| 평가 지표 | MSE, MAE |
| 실행 장치 | CUDA 사용 가능 시 GPU, 그렇지 않으면 CPU |

## 실행 방법

### 1. 환경 준비

Python 3 환경에서 아래 라이브러리를 설치합니다.

```bash
pip install numpy pandas matplotlib seaborn scikit-learn torch jupyter
```

### 2. 데이터 전처리 및 시각화

프로젝트 폴더에서 Jupyter Notebook을 실행합니다.

```bash
jupyter notebook AirQualityUCI_Preprocessing_Visualization.ipynb
```

노트북에서 데이터 전처리 결과, 주요 오염물질의 시계열 변화 및 변수 간 상관관계 히트맵을 확인할 수 있습니다.

### 3. 모델 학습 및 성능 비교

`AirQualityUCI.csv`와 `project.py`가 동일한 폴더에 있는지 확인한 후 다음 명령을 실행합니다.

```bash
python project.py
```

프로그램은 높은 상관관계 그룹과 낮은 상관관계 그룹 각각에 대해 4개 모델을 학습·평가합니다.

## 결과 확인

실행하면 다음 결과를 확인할 수 있습니다.

- 모델별 학습 진행 상황 및 학습 시간
- 각 모델의 테스트 **MSE**, **MAE**
- 높은 상관관계 그룹에서의 **실제값과 4개 모델 예측값 비교 그래프**
- 낮은 상관관계 그룹에서의 **실제값과 4개 모델 예측값 비교 그래프**
- 두 변수 그룹의 **모델별 MSE 비교 막대그래프**

평가 지표와 예측값은 **정규화된 벤젠 농도**를 기준으로 계산됩니다. 실제 농도 단위로 역변환한 평가 결과나 확정된 모델별 성능 수치는 현재 저장소 코드에 포함되어 있지 않습니다.

## 참고 및 유의사항

- **현재 구현 상태:** 정규화가 학습/테스트 분리 전에 전체 데이터에 적용되어 테스트 구간의 정보가 스케일 범위 계산에 반영됩니다. 보다 엄밀한 성능 평가를 위해서는 학습 데이터에만 스케일러를 학습시키고 테스트 데이터에는 변환만 적용해야 합니다.
- **데이터 연속성:** 결측 행 제거 후에도 시계열을 그대로 이어서 사용하므로, 24개 관측치가 항상 연속된 24시간을 나타내지는 않습니다.
- **재현성:** 난수 시드가 고정되어 있지 않으므로 학습 결과가 실행할 때마다 달라질 수 있습니다.
- **글꼴:** 그래프의 한글 표시에는 Windows의 `Malgun Gothic`을 사용합니다. 다른 운영체제에서는 설치된 한글 글꼴로 변경해야 할 수 있습니다.
