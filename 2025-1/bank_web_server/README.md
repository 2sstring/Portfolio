# bank_web_server

Flask를 활용하여 구현한 **간단한 은행 계좌 관리 웹 애플리케이션**입니다.  
사용자가 로그인하면 계좌 잔액을 확인하고 입금·출금 기능을 이용할 수 있습니다. Python 기반 웹서버의 기본 구조와 Flask의 라우팅, 세션 및 HTML 템플릿 사용 방법을 학습하기 위한 프로젝트입니다.

## 1. 주요 기능

| 기능 | 설명 |
| --- | --- |
| 로그인 | 등록된 아이디와 비밀번호를 확인하여 로그인합니다. |
| 잔액 조회 | 로그인한 사용자의 이름과 현재 계좌 잔액을 표시합니다. |
| 입금 | 입력한 금액을 잔액에 더하고 처리 결과를 표시합니다. |
| 출금 | 잔액이 충분한 경우 입력한 금액을 차감합니다. |
| 오류 메시지 | 로그인 실패, 숫자가 아닌 금액 입력, 잔액 부족 등을 안내합니다. |
| 로그아웃 | 세션을 초기화하고 로그인 화면으로 돌아갑니다. |

## 2. 프로젝트 폴더 구조

```text
bank_web_server/
├── app.py              # Flask 웹서버, 로그인 및 입출금 처리
├── templates/
│   └── main.html       # 로그인 및 계좌 관리 웹 화면
└── README.md           # 프로젝트 설명 문서
```

- **`app.py`**: Flask 애플리케이션을 실행하고 사용자 인증, 세션 관리, 잔액 변경을 처리합니다.
- **`templates/main.html`**: Jinja2 템플릿을 사용해 로그인 화면과 계좌 관리 화면을 조건에 따라 표시합니다.

## 3. 사용 기술

- **Python**: 서버 로직 구현
- **Flask**: 웹서버 및 URL 라우팅
- **HTML / Jinja2**: 웹 화면 구성 및 데이터 출력
- **Flask Session**: 로그인 상태 유지

## 4. 설치 및 실행 방법

### ① Flask 설치

Python이 설치된 환경에서 다음 명령어를 실행합니다.

```bash
pip install flask
```

### ② 서버 실행

`bank_web_server` 폴더로 이동한 후 다음 명령어를 실행합니다.

```bash
python app.py
```

### ③ 웹페이지 접속

웹 브라우저에서 아래 주소를 입력합니다.

```text
http://127.0.0.1:5000/
```

## 5. 테스트 계정

현재 코드는 학습용 계정 정보를 `app.py` 내부에 직접 정의하고 있습니다.

| 항목 | 값 |
| --- | --- |
| 아이디 | `admin` |
| 비밀번호 | `1234` |
| 화면에 표시되는 이름 | `user1` |
| 초기 잔액 | `1,000원` |

> 위 계정은 코드에 포함된 **실습용 계정**이며, 실제 서비스에서 사용해서는 안 됩니다.

## 6. 사용 방법

1. 웹페이지에 접속해 아이디와 비밀번호를 입력합니다.
2. 로그인에 성공하면 사용자 이름과 현재 잔액이 표시됩니다.
3. 금액을 입력하고 **입금** 또는 **출금** 버튼을 누릅니다.
4. 처리 결과와 변경된 잔액을 확인합니다. 출금 금액이 잔액보다 크면 잔액 부족 메시지가 표시됩니다.
5. **로그아웃**을 누르면 로그인 화면으로 돌아갑니다.

## 7. 주요 코드 동작

| 경로 | 요청 방식 | 역할 |
| --- | --- | --- |
| `/` | `GET` | 로그인 여부에 따라 로그인 또는 계좌 관리 화면 표시 |
| `/` | `POST` | 로그인 요청 또는 입금·출금 요청 처리 |
| `/logout` | `GET` | 세션 초기화 후 메인 페이지로 이동 |

`main.html`은 서버에서 전달한 `mode` 값에 따라 로그인 화면(`login`)과 계좌 관리 화면(`dashboard`)을 구분하여 렌더링합니다.

## 8. 참고 및 주의사항

이 프로젝트는 **Flask 웹 프로그래밍 학습용 예제**이며, 실제 은행 서비스가 아닙니다.

- 사용자 정보와 잔액은 **Python 딕셔너리에만 저장**되므로 서버를 재시작하면 초기값으로 돌아갑니다.
- 별도의 데이터베이스나 회원가입 기능은 구현되어 있지 않습니다.
- 비밀번호와 Flask 세션 비밀키가 코드에 직접 작성되어 있고, 디버그 모드(`debug=True`)로 실행됩니다.
- 현재 코드에는 입출금 금액의 **양수 여부 검증**이 없어 0원 또는 음수 입력을 제한하지 않습니다.
- 따라서 실제 운영 환경에 배포하려면 입력값 검증, 비밀번호 해싱, 비밀키 환경변수 관리, CSRF 방어, 데이터베이스 연동 및 디버그 모드 비활성화 등의 보완이 필요합니다.
