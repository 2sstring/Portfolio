Python의 **OpenCV**를 이용해 이미지·동영상을 읽고 화면에 표시하는 방법부터 색상 공간 변환, 히스토그램 분석, 색상 추출, 공간 필터 기반 경계 검출까지 영상처리의 기본 기능을 학습합니다.

| 실습 차시 | 3주차 |
| 실습 주제 | OpenCV를 활용한 기초 영상처리 |
| 실습 방식 | 수업 시간에 제공된 설명 및 예제를 따라 실행·확인 |

| 주요 라이브러리 | OpenCV (`cv2`), NumPy, Matplotlib |

## 🧩 실습 파일별 내용

| 파일 | 실습 주제 | 주요 기능 및 확인 내용 |
|---|---|---|
| `main.py` | Python 실행 확인 | PyCharm 기본 생성 예제의 문자열 출력 (`Hi, PyCharm`) |
| `ex1.py` | 이미지 불러오기 | `Lenna.png`를 흑백으로 읽고 창에 출력 |

| `ex4.py` | BGR 채널 분석 | 이미지의 Blue·Green·Red 채널 분리 및 채널별 색상 표시 |

| `ex8.py` | 색상별 히스토그램 | BGR 각 채널의 히스토그램 및 통계량 출력 |
| `ex9.py` | 엣지 검출 | Sobel, Laplacian, Prewitt, Roberts, 사용자 정의 커널 비교 |

### 주요 학습 개념

- **영상 입력 및 출력:** `cv2.imread()`, `cv2.imshow()`, `cv2.VideoCapture()`, `cv2.waitKey()`
- **색상 표현:** 그레이스케일, BGR, YUV, HSV와 채널 분리
- **영상 분석:** 픽셀 밝기 분포 및 색상 채널별 히스토그램
- **객체 색상 추출:** `cv2.inRange()`를 이용한 색상 마스크와 모폴로지 연산
- **공간 필터링:** 가우시안 블러 및 `cv2.filter2D()` 기반 경계 검출

## 🛠️ 실행 환경 및 설치

- Python 3 환경
- 화면을 표시할 수 있는 데스크톱 실행 환경(Windows 등)
- `ex3.py` 실행 시 사용 가능한 웹캠 및 카메라 접근 권한
- `ex8.py`에서 지정한 `TkAgg` 백엔드를 사용하려면 Tk 지원 환경 필요

```bash
pip install opencv-python numpy matplotlib
```

`opencv-python`은 일반 GUI 창을 사용할 수 있는 패키지입니다. GUI 창을 띄울 수 없는 일부 서버·노트북 환경에서는 `cv2.imshow()` 예제가 그대로 동작하지 않을 수 있습니다.

## 🚀 실습 코드 실행 방법

터미널에서 저장소 폴더로 이동한 뒤 원하는 예제를 실행합니다.

```bash
cd using_opencv

# 이미지 처리 예제
python ex1.py
python ex4.py
python ex5.py
python ex6.py
python ex7.py
python ex8.py
python ex9.py

# 동영상 및 웹캠 예제
python ex2.py
python ex3.py
```

- `ex1.py`, `ex4.py`~`ex7.py`, `ex9.py`: OpenCV 창에서 키 입력 후 종료합니다.
- `ex2.py`, `ex3.py`: 표시 중 **`q` 키**를 누르면 실행을 종료합니다.
- `ex8.py`: Matplotlib 그래프 창을 순서대로 확인·닫아야 다음 그래프가 표시될 수 있습니다.
- `main.py`: OpenCV 학습 코드가 아닌 PyCharm 기본 실행 예제입니다.

## ⚠️ 실행 및 활용 시 주의사항

1. **입력 파일명 확인:** 코드의 `Lenna.png`, `candies.png`, `desert.JPG`, `test_video.mp4`와 파일명·대소문자가 정확히 일치해야 합니다.
2. **실행 위치 확인:** 상대 경로를 사용하므로 프로젝트 루트가 아닌 다른 위치에서 실행하면 이미지를 찾지 못할 수 있습니다.
3. **그래픽 환경 필요:** `cv2.imshow()`는 GUI가 필요하며, `ex8.py`는 `TkAgg` 설정으로 인해 환경에 따라 추가 설정이 필요할 수 있습니다.
4. **카메라 사용:** `ex3.py`는 웹캀이 연결되어 있어야 하며, 다른 프로그램이 카메라를 점유하면 열리지 않을 수 있습니다.
5. **실습용 결과 해석:** `ex9.py`의 필터 결과는 각 엣지 검출 기법을 비교하기 위한 예제로, 정밀한 정량 평가나 산업용 검사 성능을 검증한 결과는 아닙니다.
6. **출처와 공개 범위:** 이 저장소는 수업 예제를 따라 학습한 기록입니다. 코드, 이미지, 영상의 원 출처와 재배포 가능 여부는 수업 자료 및 제공 조건을 확인해야 합니다.
