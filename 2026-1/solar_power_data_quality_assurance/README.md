# ☀️ Solar Power Data Quality Assurance

### 태양광 발전량 데이터 품질 검증 및 전처리

태양광 발전량 예측을 위한 공공데이터를 대상으로 **유일성(Uniqueness), 완전성(Completeness), 유효성(Validity), 일관성(Consistency), 정확성(Accuracy)**을 점검하고, 분석에 활용할 수 있는 정제 데이터셋을 생성하는 Python 프로젝트입니다.

발전일자·지역·기상 조건·설비용량·발전량 등의 데이터를 대상으로 중복 및 결측값을 처리하고, 물리적 범위와 야간 발전량 조건을 검토합니다. 이 저장소는 **예측 모델 학습이 아니라 데이터 품질 확보 단계**에 초점을 맞춥니다.

| `01. 전국 태양광 발전량 예측값 학습데이터.csv` | 원본 입력 데이터 (GitHub 저장소에 포함되지 않음) |

| 읽기 인코딩 | `cp949` |

### 📥 다운로드 및 준비 방법

1. 위 데이터 페이지에서 원본 CSV 파일을 다운로드합니다.
2. CSV 파일을 `solar_power.py`와 **같은 폴더**에 배치합니다.
3. 파일명을 `01. 전국 태양광 발전량 예측값 학습데이터.csv`로 맞춥니다. 다른 이름을 사용한다면 `solar_power.py`의 `file_path`를 변경해야 합니다.
4. 아래 실행 방법에 따라 코드를 실행합니다.

주요 참조 컬럼은 `시도명`, `발전일자`, `윤년여부`, `설비용량(MW)`, `기온`, `습도`, `풍속`, `적운량(10분위)`, `적운량(3분위)`, `일조(hr)`, `대기권밖일사량계산값`, `일사량`, `발전량(MWh)`입니다. 다운로드한 파일의 실제 컬럼명이 코드와 일치하는지 확인해 주세요.

> ⚠️ **원본 데이터 안내:** 본 저장소에는 원본 데이터 CSV를 포함하지 않습니다. 데이터를 직접 다운로드하여 준비해야 하며, 실제 데이터 없이 전처리 결과를 생성할 수 없습니다.

## 🔄 데이터 처리 흐름

```text
원본 태양광 발전량 CSV
        ↓
① 유일성 검사 — 지역·발전일자 중복 제거
        ↓
② 완전성 검사 — 결측률 분석 및 결측 처리
        ↓
③ 유효성 검사 — 날짜·자료형·값 범위 검증
        ↓
④ 일관성 검사 — 야간 발전량 0 보정
        ↓
⑤ 정확성 검사 — 설비용량 대비 발전량 검토
        ↓
solar_preprocessed.csv
```

## 🧹 주요 데이터 품질 처리

| 단계 | 품질 요소 | 실제 코드의 처리 방식 |
|---|---|---|
| 1 | **유일성** | `시도명`, `발전일자`가 같은 중복 행을 제거하고 제거 건수 출력 |
| 2 | **완전성** | 결측률 **80% 이상**인 컬럼 제거 → 지정 야간 조건에서 일조·일사량의 결측값을 0으로 대체 → 남은 결측 행 제거 |
| 3 | **유효성** | 날짜를 `datetime`으로 변환하고 문자열 공백 정리, 수치형 변환 및 허용 범위 검사 |
| 4 | **일관성** | `대기권밖일사량계산값 == 0`이고 `일사량 == 0`인 행의 `발전량(MWh)`을 0으로 보정 |
| 5 | **정확성** | `발전량(MWh) <= 설비용량(MW)` 조건을 만족하지 않는 행 제거 |

### 유효성 검증 기준

| 변수 | 적용 기준 |
|---|---|
| 설비용량(MW) | 0보다 큼 |
| 발전량(MWh) | 0 이상 |
| 기온 | -30 ~ 50 |
| 습도 | 0 ~ 100 |
| 풍속 | 0 이상 |
| 적운량(10분위) | 0 ~ 10 |
| 적운량(3분위) | 0 ~ 3 |
| 일조(hr) | 0 ~ 1 |
| 대기권밖일사량계산값 | 0 이상 |
| 일사량 | 0 이상 |

범위 검사는 코드에 정의된 규칙을 그대로 기술한 것으로, 모든 지역·측정 주기에 적용되는 보편적인 품질 기준을 의미하지는 않습니다.

## ⚠️ 실행 및 결과 해석 시 주의사항

- **데이터 단위·시간 간격 확인:** 현재 정확성 규칙인 `발전량(MWh) <= 설비용량(MW)`는 발전량이 **1시간 단위 에너지**라는 가정에서 적용 가능한 단순 기준입니다. 일별·월별 집계 자료이거나 측정 간격이 다르면 그대로 적용하기 어렵습니다. 이 경우 측정 기간을 반영하여 기준을 재설정해야 합니다.
- **중복 판단 기준 확인:** 코드에서는 `시도명`과 `발전일자`만으로 중복을 판단하고 첫 행만 남깁니다. 한 지역·일자에 정상적으로 여러 건이 존재하는 데이터라면 일부 기록이 제거될 수 있습니다.
- **필수 컬럼 확인:** 결측률 80% 이상인 컬럼은 일괄 제거됩니다. 이때 `일조(hr)`, `일사량`, `대기권밖일사량계산값` 등 이후 코드가 참조하는 컬럼이 삭제되면 `KeyError`가 발생할 수 있습니다. 실행 전 데이터 구조를 확인해야 합니다.
- **야간 보정 조건 확인:** 두 일사 관련 값이 0인 행을 야간으로 취급하여 발전량을 0으로 바꾸는 것은 이 프로젝트에서 정한 처리 규칙입니다. 실제 발전소의 기록 지연이나 측정 오류 여부를 별도로 검토하는 것이 좋습니다.
- **검증 결과의 의미:** 데이터 정제 및 규칙 기반 이상치 제거를 수행하는 프로젝트이며, 예측 모델의 성능이나 처리 후 데이터의 완전한 정확성을 보장하지는 않습니다.

## 🎯 프로젝트 목적

태양광 발전량 데이터의 중복, 결측, 비정상 값 및 변수 간 불일치를 체계적으로 점검하고, 이후 발전량 예측·통계 분석에 사용할 수 있는 **일관된 전처리 데이터셋**을 생성하는 것이 목적입니다.
