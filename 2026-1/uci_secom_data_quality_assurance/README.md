# 🏭 uci_secom_data_quality_assurance

**UCI SECOM 반도체 제조 공정 데이터의 품질 검증 및 전처리 프로젝트**

반도체 제조 공정에서 수집된 고차원 센서 데이터를 대상으로 **유일성(Uniqueness), 완전성(Completeness), 유효성(Validity), 일관성(Consistency), 정확성(Accuracy)**의 다섯 가지 관점에서 데이터 품질을 점검합니다. 중복 기록, 결측값, 통계적 이상치, 비수치형·상수 특징을 단계적으로 처리하고, 정제 전후의 통계량을 비교하여 이후 불량 판정 모델 개발에 활용할 수 있는 데이터를 준비합니다.

> 💡 **프로젝트 범위:** 이 저장소는 **데이터 품질 확보를 위한 전처리 및 검증** 프로젝트입니다. 머신러닝 분류 모델의 학습, 불량 예측 성능 측정, 예측 서비스 배포는 포함하지 않습니다.

## ⚙️ 데이터 품질 처리 과정

### ① 유일성 (Uniqueness)

전체 컬럼 값이 동일한 **완전 중복 행**을 제거합니다.

```python
df_uni = df.drop_duplicates()
```

처리 전후 행 수와 제거된 중복 행 수를 콘솔에 출력합니다. 특정 센서나 시각만을 기준으로 중복을 제거하지는 않습니다.

### ② 완전성 (Completeness)

센서 특징별 결측률을 계산하여 **결측률이 10% 이상인 특징을 제거**하고, 남은 컬럼에 결측값이 존재하는 행을 제거합니다.

```python
missing_ratio = df_uni[feature_cols].isnull().mean()
kept_features = missing_ratio[missing_ratio < 0.1].index.tolist()
df_com = df_uni[['Time'] + kept_features + ['Pass/Fail']].dropna().copy()
```

| 구분 | 처리 기준 |
|---|---|
| 특징 제거 | `결측률 >= 0.10` |
| 특징 유지 | `결측률 < 0.10` |
| 행 제거 | 유지한 컬럼 중 결측값이 하나라도 있는 행 |
| 제외 컬럼 | `Time`, `Pass/Fail`은 특징별 결측률 산정 대상에서 제외 |

결측 데이터의 평균값 대체나 보간은 수행하지 않습니다.

### ③ 유효성 (Validity)

특징별 사분위수 범위(IQR)로 이상치 경계를 구합니다.

\[
\mathrm{IQR}=Q_3-Q_1
\]

\[
\mathrm{Lower}=Q_1-1.5\,\mathrm{IQR},\qquad
\mathrm{Upper}=Q_3+1.5\,\mathrm{IQR}
\]

각 행에서 범위를 벗어난 **특징의 비율**을 계산하고, **4% 이상인 행을 제거**합니다.

```python
outlier_ratio = outlier_mask.sum(axis=1) / len(validity_feature_cols)
df_valid = df_com[outlier_ratio < 0.04].copy()
```

즉, 센서값 하나가 이상치라는 이유만으로 해당 행을 삭제하는 방식은 아닙니다. 또한 이상치 값을 보정하는 대신 조건에 해당하는 **행 전체를 제외**합니다.

### ④ 일관성 (Consistency)

특징들의 자료형과 변동성을 검사합니다.

| 검사 항목 | 처리 방법 |
|---|---|
| 비수치형 특징 | `np.number` 자료형이 아닌 센서 특징 제거 |
| 상수 특징 | 분산이 정확히 `0`인 특징 제거 |
| 유지 항목 | `Time`, `Pass/Fail`은 상수·비수치 특징 검사 대상에서 제외 |

이 단계가 끝난 데이터를 `uci-secom_cleaned_until_consistency.csv`로 저장합니다.

### ⑤ 정확성 (Accuracy) 검증

최초 원본 데이터와 정제된 데이터에서 **공통으로 남아 있는 센서 특징**을 대상으로 아래 항목을 비교합니다.

| 비교 지표 | 코드에서 수행하는 계산 |
|---|---|
| IQR 기반 이상치 개수 | 정제 전·후의 특징별 이상치 수 합계 |
| 이상치 감소량 | 정제 전 이상치 수 − 정제 후 이상치 수 |
| 표준편차 감소 특징 수 | 정제 후 표준편차가 작아진 공통 특징의 개수와 비율 |

> **중요:** 이 단계는 이상치 수와 데이터 분산의 변화를 살펴보는 **통계적 비교**입니다. 실제 센서 측정값의 참값과 대조하여 정확도를 검증하거나 정제 CSV를 추가로 수정하는 단계는 아닙니다. 전후 IQR 경계도 각각의 데이터에서 다시 계산하므로, 결과는 그 기준에 따른 비교값입니다.

## ⚠️ 참고 및 주의사항

1. **입력 형식이 중요합니다.** 코드가 `Time`, `Pass/Fail` 컬럼을 직접 참조하므로 반드시 해당 컬럼을 포함해야 합니다.
2. **결측 행 삭제에 따른 데이터 감소:** 결측률이 높은 특징을 제거한 뒤에도 남아 있는 결측 행은 전부 제외됩니다. 데이터 및 소수 클래스의 손실 여부를 확인해야 합니다.
3. **고장/불량 클래스 보존:** IQR 기반 행 제거는 소수 클래스의 드문 패턴까지 제거할 수 있으므로, 단계별 `Pass/Fail` 분포를 확인해야 합니다.
4. **임계값은 실험 설정입니다.** 특징 결측률 10%, 행 이상치 비율 4%, IQR 계수 1.5는 현재 코드에 적용된 설정이며 모든 제조 데이터에 보편적으로 타당한 기준은 아닙니다.
5. **수치형 입력 가정:** 유효성 단계에서 사분위수를 계산한 뒤 일관성 단계에서 비수치 특징을 제거합니다. 비수치 센서 컬럼이 들어 있는 경우 pandas 버전·데이터 형식에 따라 유효성 단계에서 먼저 오류가 발생할 수 있습니다.
6. **모델링 시 데이터 누수 주의:** 현재 코드는 원본 전체에서 결측률 및 이상치 기준을 계산합니다. 추후 Train/Test 성능을 엄밀하게 평가하려면 분할 이후 학습 데이터에서 정제 기준을 산정하고 다른 분할에 동일하게 적용하는 방식을 검토해야 합니다.
7. **정확성의 의미:** 전처리 전후 이상치 개수와 표준편차를 비교한 결과가 공정 데이터의 물리적 진실성 또는 품질 판정 정확도를 보장하지는 않습니다.
8. **실행 경로:** 입력·출력 파일명 모두 상대 경로이므로 `uci_secom.py`와 원본 CSV가 있는 프로젝트 폴더에서 실행하는 것을 권장합니다.
