# ☀️ pv_correlation_analysis

**태양광 발전 데이터의 입력 변수 간 상관관계 및 발전량 관련 변수 분석 프로젝트**

Python을 활용하여 태양광 발전 데이터의 **피어슨(Pearson) 상관계수**를 계산하고, 전체 변수 간 상관관계를 히트맵으로 시각화합니다. 데이터에 `Target` 열이 포함되어 있다면 해당 열과 각 숫자형 변수의 상관계수도 별도로 정리하여 CSV로 저장합니다.

> ⚠️ **데이터 공개 안내:** `SolarData_60min_for_train.csv`에는 공개할 수 없는 원본 데이터가 포함되지 않습니다. GitHub에 업로드된 파일은 **비어 있는 파일**이므로, 실제 분석을 실행하려면 별도로 이용 권한이 있는 데이터를 준비해야 합니다.

---

## 📌 프로젝트 개요

주요 작업은 다음과 같습니다.

- 태양광 발전 데이터 CSV 불러오기 및 데이터 구조 확인
- 숫자형 변수만 선택하여 **Pearson 상관계수 행렬** 계산
- 전체 상관계수 행렬을 CSV 파일로 저장
- 변수 간 상관관계를 **히트맵(Heatmap)**으로 시각화
- `Target` 열이 존재하는 경우, 해당 변수와 다른 변수들의 상관계수를 내림차순으로 정렬하여 저장

| `README.md` | 프로젝트 소개, 사용 방법 및 유의사항 |

## 🗂️ 사용 데이터

- **입력 파일:** `SolarData_60min_for_train.csv`
- **데이터 형태:** CSV 형식의 태양광 발전 관련 데이터
- **시간 단위:** 파일명 기준 60분 데이터
- **분석 변수:** CSV에 포함된 숫자형 열
- **기준 변수:** `Target` (해당 열이 존재하고 숫자형인 경우에만 별도 분석)

데이터의 실제 열 목록과 관측치 수는 공개되지 않은 원본 데이터에 따라 달라집니다. 현재 GitHub에 포함된 빈 CSV만으로는 상관계수를 계산할 수 없습니다.

### 🔒 원본 데이터 안내

`SolarData_60min_for_train.csv`는 **공개할 수 없는 데이터**이므로 원본 측정값을 GitHub에 제공하지 않습니다. 저장소에 있는 빈 파일은 데이터의 존재와 필요한 파일명을 안내하기 위한 것으로, 예제 수치 또는 실제 측정 데이터가 들어 있지 않습니다.

실행 시에는 사용 권한이 있는 데이터를 동일한 파일명으로 준비하고, 필요한 경우 `corr_with_target.py`의 경로를 수정해야 합니다.

## ⚙️ 데이터 분석 과정

| 단계 | 처리 내용 |
| --- | --- |
| 1. 데이터 로드 | `pandas.read_csv()`로 태양광 발전 데이터 불러오기 |
| 2. 변수 선택 | `select_dtypes()`를 사용하여 숫자형 열만 추출 |
| 3. 상관계수 계산 | `corr(method="pearson")`로 숫자형 변수 간 상관계수 행렬 생성 |
| 4. 결과 저장 | 전체 상관계수 행렬을 CSV 파일로 출력 |
| 5. 히트맵 시각화 | `seaborn.heatmap()`을 사용하여 상관계수 행렬 시각화 및 PNG 저장 |
| 6. Target 분석 | `Target` 열이 있으면 해당 열과 각 변수의 상관계수를 내림차순 정렬하여 CSV 저장 |

### 📊 Pearson 상관계수

Pearson 상관계수는 두 변수 사이의 **선형 관계의 방향과 강도**를 나타내며, 값은 -1부터 1까지입니다.

| 상관계수 | 해석 |
| --- | --- |
| 1에 가까움 | 강한 양의 선형 상관관계 |
| 0에 가까움 | 선형 상관관계가 약하거나 없음 |
| -1에 가까움 | 강한 음의 선형 상관관계 |

> 상관관계는 변수 간 선형적인 연관성을 보여주지만, **인과관계를 의미하지는 않습니다**. 또한 일정한 값만 갖는 변수 등의 상관계수는 계산되지 않을 수 있습니다.

## 🚀 실행 방법

### 1. 프로젝트 폴더로 이동

```bash
cd pv_correlation_analysis
```

### 2. 필요한 라이브러리 설치

```bash
pip install pandas numpy matplotlib seaborn
```

### 3. 데이터 준비

분석 권한이 있는 태양광 발전 데이터를 `SolarData_60min_for_train.csv`라는 이름으로 준비합니다. **GitHub의 빈 CSV 파일 자체는 분석에 사용할 수 없습니다.**

### 4. 데이터 경로 설정

현재 `corr_with_target.py`는 데이터 폴더를 아래와 같이 **Windows 절대경로**로 지정합니다.

```python
DATA_DIR = r"C:\pv_sys"
DATA_PATH = os.path.join(DATA_DIR, "SolarData_60min_for_train.csv")
```

실제 CSV를 해당 경로에 두거나, 저장소 폴더에서 바로 실행하려면 `DATA_DIR` 부분을 다음과 같이 변경할 수 있습니다.

```python
DATA_DIR = os.path.dirname(os.path.abspath(__file__))
DATA_PATH = os.path.join(DATA_DIR, "SolarData_60min_for_train.csv")
```

위와 같이 수정하면 입력 CSV와 분석 결과 파일이 `corr_with_target.py`가 있는 폴더를 기준으로 관리됩니다.

### 5. 분석 코드 실행

```bash
python corr_with_target.py
```

실행 후 데이터 크기와 숫자형 변수 개수, 결과 파일 저장 위치 등이 콘솔에 표시됩니다.

## ⚠️ 참고 및 주의사항

- **비공개 데이터:** 원본 태양광 발전 측정 데이터는 제공되지 않으며, 빈 CSV 파일만 포함되어 있습니다.
- **실행 전 준비:** 유효한 숫자형 열이 포함된 CSV를 별도로 준비해야 합니다.
- **경로 설정:** 코드에 지정된 `C:\pv_sys`는 개인 환경의 경로이므로 사용하는 컴퓨터에 맞게 변경해야 합니다.
- **기준 변수:** `Target` 열이 없거나 숫자형이 아니면 Target 기준 상관계수 CSV는 생성되지 않습니다.
- **분석 범위:** 현재 코드는 숫자형 변수 간 상관관계를 계산하는 **탐색적 분석**이며, 발전량 예측 모델 학습이나 예측 성능 평가 기능은 포함하지 않습니다.
- **결과 해석:** 상관계수가 높더라도 해당 변수가 발전량 변화의 원인이라고 단정할 수 없습니다.
