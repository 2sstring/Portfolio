# 🗺️ chungbuk_land_use_classification

**충청북도 시·군·구별 토지이용 특성을 활용한 K-Means 기반 유형 분류 프로젝트**

2015~2025년 충청북도의 지적통계 및 주민등록인구통계를 바탕으로 토지이용 비율, 인구밀도, 도로율 등의 특징을 구성하고, **K-Means 군집화**를 통해 지역별 토지이용 유형을 비교·분석합니다. 입력 특징을 4개, 6개, 20개 및 전체 특징으로 달리하고, 군집 수(`k=2, 3, 4`)에 따른 분류 결과를 **PCA 시각화와 Softmax 기반 군집 소속도**로 살펴봅니다.

> 이 프로젝트는 정답 레이블을 학습하는 지도학습 분류가 아니라, 유사한 토지이용 특성을 가진 지역을 묶는 **비지도학습 군집 분석**입니다.

---

## 📌 프로젝트 개요

주요 작업은 다음과 같습니다.

- 충청북도 **연도별·지역별 토지이용 자료** 수집 및 통합
- 임야, 농경지, 대지, 공장용지 등 토지이용 면적을 **비율 특징**으로 변환
- 인구자료와 도로면적 자료를 활용한 **인구밀도·도로율** 계산
- 특징 그룹별 **K-Means(`k=2, 3, 4`)** 군집 결과 비교
- 군집 중심의 토지이용 특성을 분석하여 도시·산업·농업·산림 관련 유형 부여
- **PCA 2차원 산점도**, 군집별 소속도 및 **2025년 지역별 분류 지도** 시각화

## ⚙️ 데이터 전처리

| 파일 | 입력 | 주요 처리 | 생성 예정 파일 |
| --- | --- | --- | --- |
| `preprocess1.py` | `chungbuk_data_*.csv` | 연도별 자료 통합, 농경지(전+답) 계산, 주요 토지 비율 산출 | `chungbuk_landuse_composition_2015_2025_detail.csv`, `chungbuk_landuse_composition_2015_2025_total.csv` |
| `preprocess2.py` | `chungbuk_data_*.csv` | 도로 면적 / 전체 면적으로 도로율 산출 | `chungbuk_road_ratio_2015_2025.xlsx` (`detail`, `total` 시트) |

주요 파생 특징의 계산 기준은 다음과 같습니다.

- **토지이용 비율:** 해당 지목 면적 ÷ 지역 전체 면적
- **농경지 면적:** 전 면적 + 답 면적
- **인구밀도:** 인구 ÷ 지역 전체 면적(km²)
- **도로율:** 도로 면적 ÷ 지역 전체 면적

## 🧠 K-Means 실험 구성

| 특징 그룹 | 사용 특징 | 적용 군집 수 | 해당 코드 |
| --- | --- | --- | --- |
| **Feature 4** | 임야·농경지·대지·공장용지 비율(4개) | 2, 3, 4 | `kmeans_feature4_k*.py` |
| **Feature 6** | Feature 4 + 인구밀도 + 도로율(총 6개) | 2, 3, 4 | `kmeans_feature6_k*.py` |
| **Feature 20** | 선택한 19개 지목의 면적 비율 + 인구밀도(총 20개) | 2, 3, 4 | `kmeans_feature20_k*.py` |
| **Feature All** | 원본에 포함된 전체 지목 면적 비율 + 인구밀도(특징 수는 컬럼에 따라 달라짐) | 2, 3, 4 | `kmeans_featureall_k*.py` |

### 🔧 주요 분석 방법

| 단계 | 처리 내용 |
| --- | --- |
| 1. 특징 생성 | 면적 및 인구·도로 정보에서 비율과 밀도 계산 |
| 2. 표준화 | `StandardScaler`를 이용해 특징값의 스케일 조정 |
| 3. 군집화 | K-Means로 `k=2`, `k=3`, `k=4`를 각각 분석 |
| 4. 유형 해석 | 군집 중심의 도시·산업·농업·산림 관련 특징을 비교하여 이름 부여 |
| 5. 차원 축소 | PCA를 이용해 군집 결과를 2차원 평면에 시각화 |
| 6. 소속도 계산 | 군집 중심까지의 거리로 Softmax 값을 산출하여 유형별 상대적 소속도 표시 |

각 실험은 코드에서 `random_state=0`, `n_init=50` 등을 지정하여 K-Means를 수행합니다. **Softmax 값은 군집 중심까지의 거리를 변환한 상대적인 소속도이며, 실제 토지이용 유형에 대한 검증된 예측 확률을 의미하지 않습니다.**

군집 수에 따라 각 스크립트는 2개·3개·4개의 유형명(예: 도시/산업형, 농업/산림형, 균형형 또는 도시형·산업형·산림형·농업형)을 부여합니다. 이러한 이름은 **군집 중심 특성에 대한 해석 결과**이며, 미리 정해진 실제 정답 레이블은 아닙니다.

## 🚀 설치 및 실행 방법

### 1. 프로젝트 폴더로 이동

```bash
cd chungbuk_land_use_classification
```

### 2. 필요한 라이브러리 설치

```bash
pip install numpy pandas matplotlib scikit-learn openpyxl geopandas
```

> 기본적인 데이터 처리·군집화에는 `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `openpyxl`이 사용됩니다. `geopandas`는 지도 시각화를 실행할 때 필요합니다. 일부 지도 데이터 형식에 따라 추가 공간정보 관련 의존성이 필요할 수 있습니다.

### 3. 원본 통계값 준비

`data/` 폴더의 CSV·Excel 파일을 **실제 수치가 들어 있는 파일**로 준비합니다. 현재 제공된 빈 예시 자료만으로는 정상적인 군집 분석을 수행할 수 없습니다.

### 4. 전처리 실행

```bash
python preprocess1.py
python preprocess2.py
```

실행 전에 아래 **「⚠️ 실행 시 확인 사항」**에서 설명한 저장 경로 설정을 확인해야 합니다.

### 5. 특징 그룹별 군집 분석

```bash
# 4개 특징, 3개 군집
python kmeans_feature4_k3.py

# 6개 특징, 3개 군집
python kmeans_feature6_k3.py

# 20개 특징, 3개 군집
python kmeans_feature20_k3.py

# 전체 특징, 3개 군집
python kmeans_featureall_k3.py
```

다른 군집 수를 시험하려면 파일명 끝의 `k2`, `k3`, `k4`에 해당하는 스크립트를 실행합니다. **Feature 4와 Feature 6은 전처리 결과 파일이 필요**하며, **Feature 20과 Feature All은 연도별 원본 CSV와 인구 Excel 파일을 직접 읽습니다.**

## 📊 분석 결과 및 시각화

실행 스크립트에 따라 다음과 같은 결과를 확인할 수 있습니다.

- **군집 결과 CSV:** 지역·연도별 군집 ID, 해석된 토지이용 유형, Softmax 기반 소속도 등
- **PCA 산점도:** 특징을 2차원으로 표현하여 군집별 분포 확인
- **군집 중심 분석:** 유형별 토지이용 비율과 인구밀도·도로율의 특징 비교
- **지도 시각화:** `map.py`로 2025년 충청북도 시·군·구의 분류 결과를 지도에 표시

결과 파일은 일반적으로 `data/` 아래에 생성됩니다. 구체적인 파일명은 각 스크립트에서 지정한 이름을 따릅니다.

### 🗺️ 지도 시각화

`map.py`는 **2025년, Feature 6·k=3**의 군집 결과를 바탕으로 충청북도 행정구역에 유형별 색상을 적용합니다. 이를 위해 다음 파일이 추가로 필요합니다.

- 군집 분석 결과 CSV: `clusters_feature6_k3_softmax.csv` (군집 분석 코드가 생성하는 실제 파일명)
- 시·군·구 경계 Shapefile: `BND_SIGUNGU_PG.shp` 및 관련 구성 파일(예: `.shx`, `.dbf`, `.prj`)

현재 `map.py`는 `clusters_feature6_k3.csv`를 읽도록 작성되어 있으므로, 실행 전 **입력 파일명을 실제 생성 파일명인 `clusters_feature6_k3_softmax.csv`로 변경**해야 합니다. 경계 Shapefile도 `data/`에 별도로 준비한 후 실행합니다.

```bash
python map.py
```

## ⚠️ 실행 시 확인 사항

1. **비어 있는 예시 데이터:** 현재 제공된 `chungbuk_data_*.csv`와 `chungbuk_population.xlsx`에는 실제 분석 수치가 없으므로 원본 자료로 보완해야 합니다.
2. **전처리 저장 경로:** `preprocess1.py`와 `preprocess2.py`는 `os.chdir("data")`로 현재 폴더를 이동한 뒤 출력 경로에 다시 `data/`를 붙입니다. 그대로 실행하면 `data/data/` 경로 문제가 발생할 수 있으므로 출력 파일 경로를 현재 작업 폴더 기준으로 조정해야 합니다.
3. **전처리 집계값 확인:** `preprocess1.py`에서 충청북도 합계 비율을 계산하는 부분은 전체 면적 합계를 분모로 사용하도록 점검할 필요가 있습니다.
4. **지도 파일명 불일치:** `map.py`가 요구하는 CSV 이름과 `kmeans_feature6_k3.py`의 실제 저장 파일명이 다릅니다. 두 파일명이 일치하도록 수정해야 합니다.
5. **그림 파일명 중복:** `kmeans_feature6_k3.py`에서 그림 저장 파일명이 `clusters_feature6_k2.png`로 지정된 부분이 있어, `k=2` 결과 이미지와 이름이 겹칠 수 있습니다.
6. **데이터 기준일:** 2025년 자료는 제공된 원본 출처의 실제 통계 기준일을 확인하여 해석해야 합니다.
