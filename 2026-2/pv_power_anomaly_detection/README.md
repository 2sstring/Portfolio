# 태양광 발전량 이상 패턴 자동 탐지 및 분석

## 프로젝트 개요

본 프로젝트는 **충북 지역 태양광 발전량과 일사량 데이터를 활용하여 비정상적인 발전 패턴의 후보를 자동으로 탐지하고 시각화하는 프로그램**입니다.

공공데이터를 전처리하고 충북 지역 데이터만 추출한 뒤, 계절·시간대·일사량 조건에 따른 **기준 발전량 분포**를 계산합니다. 이후 관측 발전량이 기준보다 현저히 낮거나, 일사량 변화에도 출력이 일정하게 유지되거나, 일사량 변화가 크지 않은데 출력이 급격하게 변하는 구간을 탐지합니다.

**Random Forest, LightGBM, LSTM 등 머신러닝 모델을 학습하지 않는 규칙·통계 기반 분석**으로, 탐지된 구간을 CSV와 그래프, Markdown 보고서로 정리합니다.

> **주의:** 본 프로젝트의 탐지 결과는 **실제 설비 고장 판정이 아닌 이상 패턴 후보**입니다. 충북 지역의 집계 자료만으로 특정 발전소의 고장 여부나 원인을 확인할 수 없습니다.

- **제공기관:** 한국동서발전(주)
- **제공처:** 공공데이터포털
- **다운로드 링크:** https://www.data.go.kr/data/15151005/fileData.do?recommendDataYn=Y
- **분석 지역:** 충북
- **분석 기간:** 2020년 1월 ~ 2024년 12월
- **주요 항목:** `시도명`, `발전일자`, `설비용량(MW)`, `발전량(MWh)`, `일사량`, `대기권밖일사량계산값`, 기온·습도·풍속 등

## 주요 분석 내용

### 1. 데이터 전처리 및 충북 지역 추출

- 발전일자를 시간 형식으로 변환하고 지역·시간 기준의 중복 행을 제거합니다.
- 기상변수와 일사량의 짧은 결측 구간을 보간하며, 남아 있는 결측과 물리적 허용 범위 오류를 처리합니다.
- 24개 시간 관측값을 확보하지 못한 날짜를 제외한 후 지역별 데이터를 저장합니다.
- `시도명`이 **충북**인 행을 추출해 `한국동서발전_지역별/PV_Dataset_충북.csv`를 생성합니다.

### 2. 정상 참고 패턴 구성

관측된 시간별 발전량을 해당 시점의 설비용량으로 나누어 **정규화발전량**을 계산합니다.

```text
정규화발전량 = 발전량(MWh) / 설비용량(MW)
```

주간 관측값을 대상으로 일사량을 분위 구간으로 나눈 후, **계절·시간대·일사량 구간별 정규화발전량의 중앙값과 25% 분위값**을 산출합니다.

- 우선 `계절 + 시간대 + 일사량 구간` 기준으로 비교합니다.
- 표본이 부족하면 `계절 + 일사량 구간`, 이후 `일사량 구간`만 사용하는 기준으로 확장합니다.
- 참고 그룹은 기본적으로 **15개 이상의 표본**을 요구합니다.
- 일사량이 낮은 시간대의 오탐지를 줄이기 위해 주간 양의 일사량 중 **45% 분위값 이상**인 시점을 탐지 대상으로 선정합니다.

여기서 참고 패턴은 **전체 분석 기간의 관측 분포**로 구성하며, 미래 발전량을 예측하는 학습 모델이나 독립 검증 결과가 아닙니다.

### 3. 이상 발전 패턴 후보 탐지

| 이상 유형 | 탐지 개념 | 기본 설정 |
|---|---|---|
| **저출력 후보** | 유사 조건의 참고 발전량에 비해 실제 발전량이 현저히 낮은 경우 | 참고 중앙값의 40% 이하, 절대 차이 0.07 이상, 2시간 이상 연속 |
| **출력 정체 후보** | 일사량은 변하는데 발전량이 거의 동일하게 유지되는 경우 | 시간별 정규화발전량 차이 0.003 이하, 4시간 이상, 구간 내 일사량 변동비 22% 이상 |
| **급격한 출력 변화 후보** | 일사량 변화가 크지 않은데 정규화발전량이 급변하는 경우 | 1시간 변화량 0.15 이상, 직전 대비 상대 변화량 50% 이상, 일사량 상대 변동 17% 이하 |

시간이 1시간 간격으로 연속되지 않은 경우에는 **서로 다른 이상 구간**으로 처리합니다. 탐지 임계값은 `04_pv_anomaly_detection.py`의 명령행 옵션으로 조정할 수 있습니다.

### 4. 분석 결과 자동 저장

- 이상 유형별 **이벤트 건수와 표시된 시간 수**를 집계합니다.
- 월별로 탐지 가능한 시간 대비 이상 후보로 표시된 시간의 비율을 계산합니다.
- 시간별 원본 관측과 이상 후보 위치를 시각화합니다.
- 재현성을 위해 사용한 탐지 임계값과 참고 패턴 설정을 JSON으로 저장합니다.

## 실행 방법

Python **3.10 이상** 환경을 권장합니다. 필요한 라이브러리를 설치합니다.

```bash
pip install numpy pandas matplotlib
```

공공데이터포털에서 다운로드한 원본 CSV 파일을 **프로젝트 최상위 폴더**에 넣은 뒤 아래 파일을 순서대로 실행합니다.

```bash
python "01_data_preprocess(10).py"
python "02_region_split(20261016-045944).py"
python 03_pv_pattern_analysis.py
python 04_pv_anomaly_detection.py
python 05_pv_anomaly_report.py
```

실행 후 `results/` 폴더에서 결과 CSV·JSON·보고서를 확인하고, `results/figures/` 폴더에서 그래프를 확인할 수 있습니다.

이미 `PV_Dataset_충북.csv`가 준비되어 있다면 **1~2번 전처리/지역 분리 단계를 생략하고 3번부터 실행**해도 됩니다. 이때 파일은 다음 경로에 있어야 합니다.

```text
한국동서발전_지역별/PV_Dataset_충북.csv
```

원본 입력 파일이나 생성 데이터의 위치가 다르면 스크립트 내 경로 설정 또는 `03_pv_pattern_analysis.py`의 `--input` 옵션을 변경해야 합니다.

## 분석상의 한계 및 유의사항

- **실제 고장 라벨이 없으므로** Precision, Recall, F1-score 등 고장 분류 성능을 평가한 결과가 아닙니다.
- 기준 발전 패턴은 **2020~2024년 전체 관측치**로 구성한 탐색적 참고 분포입니다. 미래 시점 예측 성능이나 독립 테스트를 검증한 결과가 아닙니다.
- 충북 **지역 집계 자료**를 사용하므로 개별 태양광 발전소의 위치와 고장 원인을 식별할 수 없습니다.
- 그늘, 적설, 기상 조건 차이, 설비 증감, 출력 제한 등도 비정상적인 발전 패턴으로 나타날 수 있습니다.
- 기존 전처리에서 제거된 관측치나 날짜는 본 분석으로 복구되지 않습니다.
- 탐지 결과는 설정된 규칙과 임계값에 영향을 받으므로, 실제 적용 전에 조건별 민감도와 데이터 대표성을 검토해야 합니다.
